# Notes

ADHD MANAGEMENT strategy by Ruri Ohama
Relies on novelty, urgency and fun factor
Sprint categories
Urgent - due today or already overdue, regardless of type of task
Upcoming deadlines - the buffer zone
Admin - maintenance tasks: emails, scheduling, chores, replying to personal messages
Creative
Time meetings with other people and deadline tasks go to calendar, others - sprits

1. brain dump (kaizen log)
   Get everything out of your brain. Don't worry about organising, just dump it all here.
   Externalise everything. Whisper flow?
2. sort into sprints
   How it feels? What does this task actually require from me? Is it a high pressure? The urgent or deadline. If it boring, draining and not time sensitive, then admin. If it's energising or interesting, then creative.
3. pick based on energy
4. work through the sprint as one chunk
   Task switching kills momentum

Sprints should be around 2-3 hours max.

Guard rail: daily highligh:
What's one thing that would make today feel successful? Pick something that takes around 60-90 min (or less)

4PM - if you have urgent tasks you have to do them now! Regardless of the sprint
9PM - don't work

Work log:
Constantly open, when you start doing new task - log time

4 STEPS: 1. 2. 3. 4.  
KAIZEN: PLAN DO CHECK ACT

## How it works?

1. Create a new log (?) each day
2. Get everything out of your head = Brain Dump
3. Choose 1 task that will make today feel like a win = Daily Highlight. Choose depending on urgency, satisfaction, momentum or something that you've been procrastinating on. Pick something that takes 60-90 min to complete.
4. Micro-commitment - 2 min action that might help you start without resistance, something that creates the momentum - reading 5 pages, opening editor, etc...
